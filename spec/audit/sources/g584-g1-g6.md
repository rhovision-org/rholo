# #584 G1–G6 source excerpt

Retrieved 2026-11-18 from <https://github.com/rhovision-org/rholo/issues/584>. Whitespace is
normalized; the gate text is unchanged.

- **G1 — installed pins.** One selected source commit / artifact / executable SHA-256 installed
  on all four validators, with four distinct validator identities, and the genesis/bond set
  pinned. Pins collected per host by #572 and checked independently of the collector's own ok
  flag.
- **G2 — signed deploy lifecycle.** One signed native-REV transfer sampled at accepted → pooled →
  included → finalized, with timestamped observations from each of the four validators and from
  the finality/settlement endpoints.
- **G3 — no false settlement.** Before finality the transfer reads not-finalized at every
  surface; `acceptsDeploys` is never reported as settlement; the finality endpoint agrees with
  the four observations.
- **G4 — recovery without loss.** A restart (or the runbook's chosen recovery arm) finalizes the
  same deploy with no accepted work lost, and no spurious self-replay or own-key halt fires on a
  healthy key (post-#577/#578 behaviour).
- **G5 — independent observations.** The verdict rests on four validator observations plus the
  endpoints, not on one public route. Raw responses, commands, digests and UTC times are
  retained under spec/audit/evidence/ with a SHA256SUMS file that verifies from a git archive.
- **G6 — verdict.** PASS / FAIL / INCONCLUSIVE, recorded by the named independent reviewer
  against G1–G5, with the evidence record cited.
