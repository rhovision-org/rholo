## The contract

The three merge refusals become `ValidateError::Internal` and arrive at `record_block_fault`
(`casper/src/blocks/block_processor.rs`). The test drives each exact reason class — search budget,
native-relation conflict, number-channel overflow — and asserts:

- a durable `Faulted` row at `validation internal`, attempt 1, with the reason preserved;
- the block is in the process-wide outstanding set;
- the row is in `due_retries` after the first backoff;
- the attempt count reaches `MAX_FAULT_RETRIES` and does not exceed it, and the row then leaves the
  due set (quarantine);
- a settled row is not due (negative control).

## Limit

The producer path is **read, not run**: the three merge causes are expensive to construct inside the
processor, so this pins the recording/retry contract for the exact reason classes rather than an
end-to-end merge. The `Internal` arm's single `record_block_fault` call is the wiring the test
exercises indirectly; a full processor run remains unclaimed.
